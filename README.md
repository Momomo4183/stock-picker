# stock-picker — 銘柄ピックアップ

長く持つ日本株の候補を、いくつかの考え方で並べて眺めるためのページ。
売買は行わない。候補と判断材料を並べるだけ。

2026-10-18 に、最初のページ「配当株の買い場」（PER12以下・PBR1以下・配当利回り3%以上・

## 使い方

デスクトップの更新ショートカット（`run_update.bat`）をダブルクリックする。
株価の取り直し → 各ページの作成 → GitHub へ反映 まで自動で進み、
終わるとPC上でトップページが開く。スマホのページは1分ほど遅れて変わる。

```
run_update.bat            通常の更新
run_update.bat --full     1株あたりの値（EPS・BPS・配当）も必ず取り直す
run_update.bat --no-push  GitHub に反映せず手元で確認する
```

1株あたりの値は7日より古いと自動で取り直す。その回だけ10〜30分かかる
（1社ずつ問い合わせるため）。

**公開ページなので、保有銘柄などの個人情報は載せない。**

## 高配当株 15指標チェック（docs/check15.html）

note「高配当株の15指標」（https://note.com/chem_free/n/nebbb338cddeb ）の考え方で、
配当利回り3%以上・時価総額300億円以上の銘柄を、成長性・収益性・キャッシュ・財務安全性・
割安性・配当の持続性の6つの観点で並べる。記事に判断の基準がある10指標は合否をつけて
「合格数」で並べ、基準が書かれていない ROE・ROA・現金・DOE は値だけ、ビジネスモデルは
業種を手がかりとして表示する。判定の細かい決まりは `scripts/build_check15.py` の先頭に書いた。

決算書（年次4〜5期）は `scripts/fetch_statements.py` が銘柄ごとに取り、30日間使い回す
（初回は654銘柄で約2分）。

## グロース株の候補（docs/growth.html）

時価総額100億円以上・売買代金（20日平均）5,000万円以上のうち、売上・営業利益とも
年10%以上の成長（年次決算4〜5期の年平均）で、直近期も増収の銘柄を並べる。
割安さは PEG（PER ÷ 利益の成長率）で見て、低い順に並べる。1倍以下が割安の目安。

PEGの成長率は純利益と営業利益の伸びの低いほうを使い、年30%で頭打ちにする。
4〜5期前（2021〜22年度）はコロナで利益が落ち込んだ会社が多く、そこから測ると伸びが
極端に大きく出て、PEGが0近くに潰れるため（2026-09-28 に発覚）。PERが5倍未満は一時的な
利益の疑いがあるので「要確認」とし、割安の数に入れない。

**この条件で将来の値上がりが確かめられたわけではない**（決算が4〜5期しか遡れず検証できない）。

## 連続増配株（docs/renzoku.html）

第1段階（PER12倍以下・PBR1.3倍以下・ROE7%以上・ROA3%以上・配当利回り3%以上・自己資本比率35%以上・
時価総額100億円以上）と第2段階（過去10期: EPSが赤字なし・9期前の2倍以上、BPSが全期プラス、
配当は減配1回まで・無配なし）を必須とし、累進配当+1 に BPSとDOEの組み合わせ（最大+4）を足して並べる。
10期分は EDINET（金融庁）の有価証券報告書から取る（`scripts/fetch_edinet.py`、APIキーは `.edinet_key`、
公開しない）。配当は株式分割の扱いがそろっている yfinance の配当履歴を決算期ごとに合計して使う。
細かい決まりは `scripts/build_renzoku.py` の先頭に書いた。

## 期待値投資（docs/kitaichi.html）

配当利回り2.5%以上・配当性向50%以下で、売上高が10期連続で増え（11期分）、営業利益が10期で増加傾向
（直近が9期前より多く、回帰直線が右上がり。減益の期があってもよい）の銘柄。過去10年の毎月のPER
（月末の株価÷発表済みの通期EPS）の幅（下から1割〜上から1割）と、今のPERの位置を出し、
中央値以下を「買い」、上を「売り」の目安とする。売上・EPSは有価証券報告書の主要な経営指標、
営業利益は連結損益計算書（1冊に2期分なので5冊）から取る。細かい決まりは `scripts/build_kitaichi.py` の先頭。

## PER検索（Googleスプレッドシート用のデータ、docs/per/コード.csv）

銘柄ごとに過去10年の毎月の 株価・EPS・PER を CSV で公開する（`scripts/build_per_data.py`）。
ご本人のスプレッドシートの「PER検索」シートが `IMPORTDATA` で読み、今の株価は `GOOGLEFINANCE` で取って
今のPERと幅の中の位置をその場で出す。PERの作り方は期待値投資と同じ。シートの式は
`自動トレード\PER検索_貼り付け用.txt`（公開リポジトリの外）。

## データの出どころ

| データ | 出どころ | 取り直す頻度 |
|---|---|---|
| 株価（日足6か月・全銘柄） | yfinance | 更新のたび（約1分） |
| 1株あたりの値（EPS・BPS・株式数・配当） | yfinance | 7日より古ければ |
| 候補の株価7年分と配当履歴 | yfinance | 更新のたび（15指標の対象だけ） |
| 過去10期のEPS・BPS・配当、配当方針の文章 | EDINET（有価証券報告書） | 新しい報告書が出たときだけ |
| 銘柄一覧 | JPX 東証上場銘柄一覧 | 月1回程度 |

PER・PBR・時価総額・配当利回りは「その日の株価 × 1株あたりの値」で計算する
（yfinance の値との一致は PER 99.8% / PBR 99.9% / 時価総額 99.8% が誤差1%以内）。
株価の取得は自宅PCから行う。Yahoo はデータセンターからの接続を拒否するため、
GitHub Actions やクラウドでは取得できない（2026-09-18 に確認）。
