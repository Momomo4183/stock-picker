# stock-picker

手動トレードを補佐するための、銘柄ピックアップ。
楽天証券スーパースクリーナーに保存している3つの条件を自前のデータで再現し、
結果をスマホから見られるページにする。**売買は行わない。候補を出すだけ。**

ページ: `docs/index.html`（GitHub Pages で公開）

## 3つの条件

| | 条件 | ねらい |
|---|---|---|
| ① | PER12以下・PBR1以下・配当利回り3%以上・時価総額700億円以上 | 割安かつ高配当で、株価が上がらなくても配当で取る |
| ② | PER7以下・PBR0.8以下・配当利回り3%未満 | より強い割安。株価の上昇をねらう |
| ③ | 時価総額300億円以上・信用倍率2.5倍以下・平均売買代金5百万円以上・25日線乖離0〜1%・RSI(14)25〜60 | スイングの入りどころ |

アプリとの件数の突き合わせ（2026-09-17 時点）は ① 52件→54件、② 69件→66件、
③ 91件→90件。指標の定義は次のとおりに決めた。

- **PER は実績**（予想PERだと②が半分以下になる。予想PERは取得できない銘柄も多い）
- **信用倍率は売残0の銘柄を除外**（含めると③がアプリより多くなる）
- RSI はワイルダー方式（単純平均との差は件数にほぼ影響しない）

## データの出どころ

| データ | 出どころ | 取り直す頻度 |
|---|---|---|
| 株価（日足6か月） | yfinance | **毎日**（全銘柄で約1分） |
| 1株あたりの値（EPS・BPS・株式数・配当） | yfinance | 週1回（1社ずつなので遅い） |
| 信用倍率 | JPX「銘柄別信用取引週末残高」PDF | 週1回 |
| 銘柄一覧 | JPX 東証上場銘柄一覧 | 月1回程度 |

PER・PBR・時価総額・配当利回りは「その日の株価 × 1株あたりの値」で計算する。
yfinance が返す値との一致は PER 99.8% / PBR 99.9% / 時価総額 99.8% が誤差1%以内
（2026-09-18 に3,707銘柄で検算）。これにより毎日の取得は株価だけで済む。

## 使い方

```
run_update.bat            毎日の更新（株価 → ページ作成 → GitHub へ反映）
run_update.bat --full     1株あたりの値も取り直す
run_update.bat --no-push  GitHub に反映せず手元で確認する
```

株価データの取得は自宅PCから行う。Yahoo はデータセンターからの接続を拒否するため、
GitHub Actions やクラウド上では取得できない（2026-09-18 に確認済み）。

## ファイル

```
scripts/fetch_data.py         株価・財務の取得
scripts/retry_fundamentals.py 取得制限で失敗した分を1社ずつ取り直す
scripts/fetch_margin.py       JPXの週末残高PDFから信用倍率を作る
scripts/build_site.py         条件で絞ってページを作る
scripts/update.py             上をまとめて実行し、GitHubに反映する
data/                         取得したデータ（リポジトリには含めない）
docs/                         公開するページ
```
